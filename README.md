# Two Stage Resolution — ComfyUI Node

Нода для расчёта разрешений двухэтапной генерации видео.  
Ты задаёшь желаемое конечное разрешение и множитель апскейла — нода сама считает правильные значения для обоих этапов, гарантируя кратность 32.

---
![preview](1.jpg)
## Зачем это нужно

Видеомодели с двухэтапной генерацией работают так:

1. **Этап 1** — генерация в латентном пространстве при базовом (меньшем) разрешении
2. **Этап 2** — апскейл латента с множителем 1.5× или 2×, затем VAE-декодирование

VAE декодирует по схеме `2×2×2×2×2 = 32`, поэтому **оба разрешения** — и базовое, и финальное — обязаны быть кратны 32. Нода рассчитывает это автоматически.

## Использование

Нода появится в категории **`video/resolution`** под названием **`Two Stage Resolution`**.

### Входы

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `width` | INT | 1920 | Желаемая ширина финального разрешения |
| `height` | INT | 1080 | Желаемая высота финального разрешения |
| `multiplier` | выбор | 1.5 | Множитель апскейла: `1.5` или `2` |

### Выходы

| Параметр | Тип | Описание |
|---|---|---|
| `width` | INT | Базовая ширина для 1-го этапа генерации |
| `height` | INT | Базовая высота для 1-го этапа генерации |
| `info` | STRING | Текстовая строка с обоими разрешениями |

`width` и `height` подключаешь к первому этапу генератора.  
`info` подключаешь к ноде **Show Text** (например из [ComfyUI-Custom-Scripts](https://github.com/pythongosssss/ComfyUI-Custom-Scripts)) чтобы видеть оба разрешения прямо в воркфлоу.

## Пример расчёта

| Вход | Множитель | BASE (этап 1) | FACT (этап 2) |
|---|---|---|---|
| 1920 × 1080 | 1.5 | 1280 × 768 | 1920 × 1152 |
| 1920 × 1080 | 2.0 | 960 × 544 | 1920 × 1088 |
| 1280 × 720 | 1.5 | 864 × 480 | 1280 × 720 * |
| 1280 × 720 | 2.0 | 640 × 360 | 1280 × 720 |

*\* Если входное разрешение уже валидное — финал совпадёт с запрошенным.*

> Финальное разрешение может незначительно отличаться от запрошенного — оно округляется вверх до ближайшего валидного значения.

## Совместимость

Протестировано с моделями на базе **WAN 2.2 I2V** с апскейлом 1.5× и 2×.  
Должно работать с любой двухэтапной архитектурой где VAE имеет фактор сжатия 32.
